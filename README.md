# Open Data Analytics

Business Intelligence and data analytics projects built only on **public open data**, so every dataset, query and dashboard can be shared.
Each project follows the same workflow: automated ingestion with Python, modeling with SQL and a Power BI dashboard with clear business findings.

## Projects

| Project | Data source | Tools | Status |
| --- | --- | --- | --- |
| [Airline On-Time Performance](airline-on-time-performance/) | US Bureau of Transportation Statistics | Python, DuckDB (SQL), Power BI | In progress |

Upcoming: projects based on open data from the Peruvian government ([Plataforma Nacional de Datos Abiertos](https://www.datosabiertos.gob.pe/)).

## Repository conventions

- One folder per project, each with its own README, requirements and scripts.
- Raw data is never committed: every project includes a script that downloads it.
- Everything is documented in English.
